# Lighting Image Director Pro

面向灯具电商、官网、画册和广告视觉的专业图片生成 Skill。

## 和旧版相比新增
- 真正的产品结构锁定 Product Lock
- 30+ 灯具类别路由
- 安装物理逻辑
- 空间/场景自动匹配
- 材质微观表现
- LED、玻璃、水晶、亚克力等专门光学规则
- 相机、镜头、构图和景深规则
- 白底主图 / 场景图 / 横幅 / 特写 / 色温图 / 卖点图模式
- 参考图“最小改动”编辑规则
- 批量 10 张、20 张场景差异化引擎
- 高清放大与二次重绘工作流
- 100 分质量检查表
- 负面提示词分类型库
- Prompt 自动编译器
- 场景库和示例

## 推荐调用
将 `SKILL.md` 作为主规则，同时按任务加载 `modules/` 中对应模块。

日常最快使用：打开 `templates/QUICK_CALL_CN.md`，填入产品与本次任务即可。
