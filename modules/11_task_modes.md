# 11 任务模式

## Mode A — White Background Main Image
目标：产品结构最清楚。
规则：白底、主体完整、边缘留白、柔和工作室光、几乎无环境干扰。

## Mode B — Grey Background Catalogue
目标：突出金属和发光面层次。
规则：浅灰背景、柔和阴影、产品居中。

## Mode C — Installed Interior Scene
目标：表现真实使用场景。
规则：空间合理、尺寸可信、产品是第一视觉中心。

## Mode D — Lifestyle Hero
目标：官网、广告、社媒高级氛围。
规则：画面更有美术设计，但结构保真不降低。

## Mode E — Detail Macro
目标：材质、工艺、接口、发光面。
规则：只聚焦真实存在的细节。

## Mode F — Color Temperature Comparison
目标：3000K/4500K/6500K。
规则：场景完全一致，只改变色温。

## Mode G — Feature Illustration
目标：遥控、调光、角度可调、IP场景等。
规则：功能必须来源于用户明确参数；不发明。

## Mode H — Reference Edit
目标：只改用户要求改变的地方。
规则：其余像素级视觉要尽量保持。

## Mode I — Product Replacement
目标：把场景图里的灯替换成参考产品。
规则：新灯结构准确，原背景、构图、曝光保持。

## Mode J — Upscale / Detail Restore
目标：清晰度提升，不重设计。
