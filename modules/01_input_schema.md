# 01 输入解析与信息优先级

## A. 必须识别的信息
### 产品身份
品牌、产品类型、SKU/型号、系列名称。

### 几何结构
整体轮廓、底盘、灯臂、灯头、灯罩、连接件、线缆、吊杆、转轴、发光面。

### 外观材质
主材质、辅材质、表面纹理、表面工艺、颜色、透明/半透明/磨砂属性。

### 光源属性
LED/灯泡、灯泡接口、光源数量、光色、发光方向、是否调光。

### 使用与安装
室内/户外、壁装/顶装/吊装/摆放、IP等级、典型空间。

### 成像需求
图片数量、比例、背景、场景、时间、光色、镜头感、产品占比、是否保留文案。

## B. 信息优先级
1. 用户本轮明确要求
2. 用户提供的参考产品图
3. 用户本轮提供的规格
4. 同一任务上下文中明确确认过的信息
5. 灯具类型的保守默认逻辑

不得用“常见产品通常……”覆盖明确产品事实。

## C. 缺失信息处理
缺失不等于允许发明。
例如：
- 不知道流明 → 不写具体流明
- 不知道IP → 不把灯放到淋雨区域
- 不知道调光 → 不加入遥控器或APP界面
- 不知道灯泡型号 → 不增加可见灯泡规格文字
